Greedy Exchange Proof Interactive Walkthroughs
Master the 4 fundamental justification shapes
Shape 1: State-Domination Swap (e.g. Lemonade Change)

Why spend $10 + $5 instead of $5 + $5 + $5 on a $20 customer?

State Domination
Step 1 · The Two Choices
Plan A (Greedy): Pay 1×$10 and 1×$5.
Plan B (Rival): Pay 3×$5.
Step 2 · Post-Transaction Wallet Delta
Compare your remaining inventory: Plan A leaves you with 2 extra $5 bills and 1 fewer $10 bill compared to Plan B.
Step 3 · Capability Dominance
A $5 bill can satisfy any customer that a $10 bill can (plus $10 customers, which a $10 bill cannot serve). Therefore, holding 2×$5 strictly dominates holding 1×$10. Plan A can never fail where Plan B succeeds.
Shape 2: Earliest-End Horizon (e.g. Non-overlapping Intervals)

Why always pick the interval with the smallest finish time?

Horizon Maximization
Visual Horizon Comparison:
Greedy [1, 3]:
[1, 3] Finishes @ 3
Free Horizon: [3, ∞)
Rival [1, 7]:
[1, 7] Finishes @ 7
Free Horizon: [7, ∞)
Core Argument: Because $3 \le 7$, the available time remaining under Greedy $[3, \infty)$ is a superset of the rival's $[7, \infty)$. Any subsequent non-overlapping choice available to the rival is also available to Greedy.
Critical Mistake Patterns & Checklist
1. Primitive vs Object Sort Space

Arrays.sort(int[]) uses Dual-Pivot Quicksort → O(log N) stack space.

Arrays.sort(int[][]) or Integer[] uses TimSort → requires an auxiliary merge buffer of up to O(N) space.

2. Ground Compressed State First

When carrying a compressed state (like (min, max) in LC 678), define what the numbers range over before coding mechanics. If you can't state what min represents, the bail-out and clamp rules will fail.

3. Trace Inputs; Never Patch Lines blindly

When a sample fails, trace the exact variables step-by-step through the logic. Guessing which line is wrong and patching it creates false regressions.

4. Set vs Sequence Distinction

Never sort an array if the sequence carries semantic temporal meaning (e.g. Lemonade Change queue). Sort only when order is arbitrary or selection-based.
