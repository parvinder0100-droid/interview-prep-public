# Core OOP in Java

## Subtopics

- Four pillars in Java specifics: encapsulation, inheritance, polymorphism (compile-time
  vs runtime), abstraction (abstract class vs interface).
- Interfaces: default/static methods, functional interfaces, multiple inheritance of type.
- Object class: equals/hashCode/toString/clone contracts, getClass vs instanceof.
- Access modifiers, package-private nuances.
- Generics: bounded types, wildcards (? extends/? super), type erasure.
- Exception handling: checked vs unchecked, try-with-resources, custom exceptions.
- Records, sealed classes, and other modern Java constructs relevant to interviews.
- Overlap with LLD: this is the language-level foundation LLD design patterns sit on.
